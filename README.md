# TravelDiscover - Travel Recommendation Website

A beautiful, responsive travel recommendation website built with HTML, CSS, and JavaScript. This project helps users discover amazing destinations including beaches, temples, and country highlights.

## 🌟 Features

- **Multiple Pages** - Home, About Us, and Contact Us pages
- **Responsive Design** - Works seamlessly across all devices
- **Destination Categories** - Beaches, temples, and country highlights
- **Contact Form** - Email form with validation
- **Interactive Elements** - Smooth scrolling and animations

## 🚀 Live Demo

Open `index.html` in your web browser to view the website locally.

## 🎨 Design Features

- Modern blue color scheme with gradients
- Responsive layout using CSS Grid and Flexbox
- Professional typography and spacing
- Mobile-first design approach

## 💻 Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with custom properties
- **JavaScript ES6+** - Interactive functionality
- **Font Awesome 6.0.0** - Professional icons
- **Unsplash Images** - High-quality photography

## 🔧 Installation & Setup

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Navigate** through the different pages using the navigation menu

No build process or dependencies required - it's a pure HTML/CSS/JavaScript project!

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: Below 768px
