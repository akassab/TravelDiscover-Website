# TravelDiscover - Travel Recommendation Website

A beautiful, responsive travel recommendation website built with HTML, CSS, and JavaScript. This project helps users discover amazing destinations including beaches, temples, and country highlights with interactive displays and detailed information.

## 🌟 Features

### Core Pages
- **Home Page** - Hero section with introduction and featured destinations
- **About Us Page** - Company story, team information, and values
- **Contact Us Page** - Contact form with validation and business information

### Navigation
- **Responsive Navigation Bar** - Works seamlessly across all devices
- **Dropdown Menus** - Easy access to different destination categories
- **Mobile-Friendly** - Hamburger menu for mobile devices

### Destination Recommendations
- **Beach Paradise** - Two stunning beach destinations with high-quality images
- **Sacred Temples** - Two historic temple recommendations with cultural insights
- **Country Highlights** - Two featured countries with diverse landscapes

### Interactive Features
- **Contact Form** - Email form with real-time validation
- **Smooth Scrolling** - Enhanced navigation experience
- **Fade-in Animations** - Engaging visual effects on scroll
- **Modal Dialogs** - Detailed destination information
- **Responsive Design** - Optimized for all screen sizes
